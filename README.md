# A Place About Falling 🧗

One shared bouldering page, many people. Each person keeps their own data in their own Google Sheet + Apps Script. The page is just the front end.

- `index.html`: the page. `?c=<deployment id>` = whose page, `?c=demo` = example data, no `?c` = landing page.
- `setup.html`: step-by-step guide for friends (DE/EN).
- `privacy.html`: privacy notice, fills in the responsible person from their setup.
- `apps-script/`: the Google side (`Code.gs`, `Setup.html`, `appsscript.json`). No secrets in here.
- `OWNER-SETUP.md`: how to host this and prepare the master sheet (German).
